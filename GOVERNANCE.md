# Governance

Miroslav Šotek, ANULUM, owns project direction, licensing and publication decisions. Contributors retain source provenance and distinguish proposals, selected contracts, implemented behaviour and qualified results.

The repository has no released runtime, hosted service or device integration. A successful local check does not authorise publishing a package, changing model equations owned elsewhere, registering an evidence format or operating hardware.

Changes need a concrete user-visible purpose, complete affected behaviour, actual validation and review. See [contribution requirements](CONTRIBUTING.md) and [support](SUPPORT.md).
