# Spike Quality Gate

Spike Quality Gate is being built to evaluate event datasets and closed capture windows against immutable, versioned quality policies. It will retain timestamp, population, exposure, polarity, rate and capture-coverage checks with complete located evidence and explicit unknowns. This checkout contains repository validation tooling and documentation. Full foundation qualification is in progress. There is no installed event-quality package, quality-check runner, public quality command or qualified quality report.

Spike Quality Gate is part of the **SC Neuromorphic Computing Systems** group (SC-NEUROMORPHIC-COMPUTING-SYSTEMS). The [group and project map](https://github.com/anulum/sc-neurocore/blob/main/docs/ecosystem.md) shows the whole programme and where this repository sits in it.

## Boundary

This project owns measurements, typed quality policy, scoped reports and independent replay of its semantics. Spike Log owns container decoding and capture closure; Spike Format Bridge owns conversion and loss ancestry. Evidence Manifest Toolkit owns shared evidence operations. Studio renders existing findings; dataset generators, benchmarks and the experiment ledger consume exact reports.

Sensor silence does not prove a capture gap or a dead pixel. Missing source, clock, exposure or coverage stays unavailable. Conversion attribution cannot remove an adverse measurement. A quality pass covers the declared checks and policy; it does not establish every downstream scientific claim.

## Current tooling

Seven repository controls inspect metadata, source attribution, workflows, dependency alignment, native documentation, inventory and preflight orchestration. Native-tool bootstrap checks selected executable and licence bytes. Domain capabilities, claims and qualified formats remain empty at architecture-only maturity.

Use the exact environment in [Contributing](CONTRIBUTING.md). Named commands are make metadata, make source-provenance, make workflows, make dependencies, make docs, make inventory and make licence. Full CI/preflight belongs in CI or an explicitly admitted pre-push environment. See [Validation](VALIDATION.md).

Read [Architecture](ARCHITECTURE.md), [support](SUPPORT.md), [security reporting](SECURITY.md) and [citation metadata](CITATION.cff). No released quality package, admitted measurement policy, actual dataset or live-capture evaluation, physical health result, DOI or hosted status is claimed.
