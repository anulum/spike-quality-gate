# Data and authority boundaries

## Present tooling

Maintained source, selected executable files and the locked tooling environment are inputs to repository controls. Received descriptors and inventories cannot select policy or acquire execution authority. Checks inspect bounded local scopes and report fixed diagnostics. Byte identity differs from interpretation and qualification.

An inventory is not a concurrent filesystem snapshot or power-failure durability guarantee. Native children use finite argument vectors and direct-child deadlines; completed-output limits are not live volume ceilings. Foundation qualification is in progress.

## Future event-data sources

Containers, policies, source records, exposure, coverage, detail data and reports are supplied data. They do not grant capture control, signing, equipment access, provider use, spending or publication authority. Earlier admitted roles and actual installed providers precede use; arbitrary labels or executable strings do not select policy.

Preserve original event order and full populations. No retrospective sampling, omitted unknown, conversion-loss subtraction, guessed exposure, silence-as-coverage or fabricated healthy result is admissible. Source refusal may prevent report construction.

Unknown clock, response model, uncertainty or current trust cannot become positive eligibility. Resources bound both working memory and retained spill/detail storage. Shared evidence and operational recovery remain separate unimplemented boundaries; no physical, isolation or durability guarantee is claimed here.
