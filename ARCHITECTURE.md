# Architecture

## Current executable surface

Repository validation tooling, dedicated tests, workflow definitions and native documentation are implemented. No domain reader, check battery, policy engine, report producer, comparison, independent domain verifier or product command is installed. Domain capability, claim and qualified-format inventories remain empty.

## Intended data flow

The admitted whole input and conversion ancestry bind an earlier complete policy, stream/channel/window inventory, clock, geometry, exposure and capture coverage. All required measurements retain located source facts. Exact typed policy and accepted uncertainty determine per-row and overall outcomes. Immutable report and detail references feed shared evidence operations, independent current verification and actual consumers.

## Ownership and interpretation

Spike Log owns parsing and capture; Spike Format Bridge owns conversion. Spike Quality Gate owns its fourteen measurements, policy and report. Evidence Manifest Toolkit owns shared evidence operations. Studio renders existing findings, with distinct consumer responsibilities for generators, benchmarks and ledger storage.

Malformed input is refused before report construction. A known failure remains visible even when another required unknown makes the overall result unknown. Read [the documentation architecture](docs/ARCHITECTURE.md).
